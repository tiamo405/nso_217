### 1. **PK Death Loop** ⚡ CRITICAL

**Triệu chứng:**
- Worker-01: 203 lần "Bi PK" trong log
- Bot bị PK chết liên tục tại zone 15
- Vòng lặp: chết → hồi sinh → bị PK lại → chết

**Nguyên nhân:**
```java
// Code cũ chỉ unlock zone nhưng KHÔNG đổi zone
if (this.zoneDeathCount >= 2) {
    this.missionZoneLocked = false;  // Unlock
    // Bot vẫn đứng zone cũ → bị PK ngay lập tức!
}
```

**Fix:**
```java
// Code mới: đổi zone NGAY sau unlock
if (this.zoneDeathCount >= 2) {
    this.missionZoneLocked = false;
    
    // ✅ Đổi zone ngay
    this.pkAvoidanceZoneOffset++;
    int nextZone = this.findNextAvailableZone(oldZone);
    super.fieldAC = nextZone;
    System.out.println("AUTO TA THU PK FIX: đổi ngay sang zone " + nextZone);
    
    Auto.fieldAA(2000L);  // Delay để map load
}
```

**File:** `ta-thu-runtime/overrides/TaThu.java`

### 2. **Worker Done Marker Path** ⚡ HIGH

**Triệu chứng:**
- 0/12 worker có marker đúng path
- 2 worker có marker sai: `workers/worker-XX/home/worker.done`
- Supervisor không detect worker complete

**Nguyên nhân:**
```java
// Code cũ
File marker = new File(System.getProperty("user.home"), "worker.done");
// user.home = /path/workers/worker-01/home
// → marker = /path/workers/worker-01/home/worker.done  ❌ SAI
```

**Fix:**
```java
// Code mới: lấy parent directory
String home = System.getProperty("user.home");
File homeDir = new File(home);
File workerDir = homeDir.getParentFile();  // workers/worker-01
if (workerDir == null || !workerDir.exists()) {
    workerDir = homeDir;
}
File marker = new File(workerDir, "worker.done");
// → marker = /path/workers/worker-01/worker.done  ✅ ĐÚNG
```

**File:** `ta-thu-runtime/src/TaThuAccountManager.java:509-518`

### 3. **Stuck Mob Detection** ⚠️ MEDIUM

**Triệu chứng:**
```
mob=35:15200/15200,mobId=53,levelBoss=0,isBoss=false
// Mob full HP, không giảm, levelBoss=0 (không phải Tà Thú)
```

**Fix:** Thêm `checkStuckMob()` method
```java
private void checkStuckMob() {
    // Kiểm tra mob HP không đổi sau 30s
    if (currentHp != this.lastMobHp) {
        this.lastMobHp = currentHp;
        this.lastMobHpChange = now;
        return;
    }
    
    if (now - this.lastMobHpChange > 30000L) {
        Mob mob = me.mobFocus;
        // Nếu không phải Tà Thú (levelBoss != 3) → clear target
        if (mob.levelBoss != 3 || mob.templateId != this.fieldAV) {
            System.out.println("AUTO TA THU WARN: mob HP stuck, clear target");
            me.mobFocus = null;
        }
    }
}
```

**File:** `ta-thu-runtime/overrides/TaThu.java:301-325`

## 🔍 Debug tips

### Xem worker nào đang stuck
```bash
./scripts/status-workers.sh --json | jq '.[] | select(.status == "running")'
```

### Xem worker nào bị PK nhiều
```bash
for w in workers/worker-*/stdout.log; do
    count=$(grep -c "Bi PK" "$w" 2>/dev/null || echo 0)
    echo "$(dirname $w): $count lần PK"
done | sort -t: -k2 -rn
```

### Xem zone nào nguy hiểm (nhiều PK)
```bash
grep "Bi PK" workers/*/stdout.log | \
    grep -oP 'zone=\K\d+' | sort | uniq -c | sort -rn | head -10
```
